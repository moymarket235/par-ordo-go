# PAR ORDO GO — BONUS V1 · бонус 3% как в PAR ORDO PRO

Карта «Бонус: 5-й вход бесплатно 0/5» заменена бонусным счётом 3%.

## Что видит гость

- **Главная → карта «Бонус 3%»**: в кольце — сколько сом бонуса доступно сейчас. Под кольцом:
  «накоплено», «использовано» и «+N после визита», если гость сейчас в бане.
  Подсказка: «Оплатите бонусом любой товар или вход — скажите администратору».
- **Бонус вырос** (визит завершён): число в кольце считает вверх, рядом всплывает «+29»,
  сообщение «+29 сом бонуса за визит 🎁 На счёте: 100 сом», колода сама поворачивается к карте бонуса.
- **Посещения**: у каждого завершённого визита — «+37 бонус», у визита со списанием — «−50 бонусом».
  Товар, оплаченный бонусом, помечен «🎁 бонусом 50». Внизу — «Бонусный счёт · 3%».
- Нет связи с сервером: показывается последний известный баланс с пометкой «Нет связи».
- Новый гость без визитов: «0 сом бонуса» и подсказка про QR.

## Как считается (так же, как в PRO)

```
накоплено    = floor(3% × сумма всех завершённых визитов)
использовано = сумма списаний бонуса во всех визитах
доступно     = накоплено − использовано
```

- Бонус за текущий визит начисляется после его завершения (до этого — «+N после визита»).
- Списание делает сотрудник в PAR ORDO PRO: на браслете кнопка «🎁 Оплатить бонусом».
  Позиция сохраняется с меткой в названии «Жарма · бонус 120» (и полем `bonusPaid`). GO находит
  списания по этой метке в `purchases[].name` — менять Worker для этого не нужно.

## Что нужно от Worker (`GET /api/go/me`)

- `visits` — **все** визиты гостя, с `status`, `sum` и `purchases[].name` как в PRO.
  Если Worker отдаёт только последние визиты, баланс в GO будет меньше, чем в PRO.
- Визиты GO-аккаунта и визиты клиента в Базе клиентов PRO должны быть одним списком
  (аккаунт связан с клиентом базы). Иначе PRO и GO покажут разные суммы.
- Необязательно: если Worker начнёт отдавать готовые цифры — `bonus: {earned, used, available}`
  или `bonusBalance` (числа), GO возьмёт их вместо своего расчёта.

## Что загрузить в корень репозитория GO (с заменой)

- `index.html` — новая карта бонуса, расчёт, пометки в посещениях.
- `par-ordo-go-bonus-v1.css` — новый файл стилей.
- `README-BONUS-GO.md`.

`sw.js` менять не нужно: страница грузится из сети, новый CSS — новый адрес.

## Проверено

Playwright с подменённым `/api/go/me`, телефон 390 px и ПК 1280 px:
обычный счёт (270 накоплено, 170 использовано → 100), рост бонуса с анимацией, новый гость без визитов,
ошибка сервера, готовые цифры от Worker, `prefers-reduced-motion`. Высота колоды на главной не изменилась
(те же шаги сжатия, что и до обновления). Ошибок в консоли нет.
