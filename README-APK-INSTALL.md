# PAR ORDO GO — PWA жана Android APK

## Эмне оңдолду

- Орнотуу панели катталуу экранында да, негизги колдонмонун бардык бөлүмдөрүндө да көрүнөт.
- Кыска экрандарда `fit-4` режими панелди жашырбайт.
- PWA manifest'ке Android талап кылган 192×192 жана 512×512 иконкалар кошулду.
- PWA орнотуу баскычы Chrome'дун `beforeinstallprompt` окуясын колдонот, ал жеткиликсиз болсо браузерге жараша нускама көрсөтөт.
- Service Worker cache версиясы жаңыртылды.
- `android/` ичинде Android WebView колдонмосу бар; ал PAR ORDO GO веб-сайтын ачат.
- `.github/workflows/android-apk.yml` APK'ни GitHub Actions аркылуу чогултуп, GitHub Release'ке `par-ordo-go.apk` аты менен чыгарат.

## APK чыгаруу

1. Өзгөртүлгөн файлдарды `moymarket235/par-ordo-go` репозиторийинин `main` бутагына жүктөңүз.
2. `android/` жана workflow файлдары кошулган commit GitHub Actions'ты автоматтык иштетет. Кааласаңыз, **Actions → Build PAR ORDO GO APK → Run workflow** аркылуу кол менен да иштете аласыз.
3. Workflow ийгиликтүү бүткөндө **Releases** бөлүмүндө `par-ordo-go.apk` пайда болот.
4. Сайттагы **Скачать APK** баскычы акыркы Release'тен APK'ни текшерип, жүктөп берет.

## Маанилүү — Android кол коюу

Азыркы биринчи APK CI runner түзгөн debug signing key менен кол коюлат. Бул тесттик/алгачкы орнотуу үчүн жарайт, бирок кийинки APK'лерге да ошол эле кол коюу ачкычы керек, болбосо Android эски версиянын үстүнө жаңыртууга уруксат бербейт. Туруктуу чыгарылышка өтөрдө жеке release keystore түзүп, анын маалыматтарын GitHub Actions Secrets'ке кошуу керек. Keystore файлды репозиторийге жүктөбөңүз.

## Коопсуз өзгөртүү

Веб-сайттын азыркы каттоо, QR, бонус, визит, профиль жана анимация файлдары сакталды. Өзгөртүүлөр PWA орнотуу катмарына, Service Worker cache версиясына жана жаңы Android wrapper/CI файлдарына гана тийет.
